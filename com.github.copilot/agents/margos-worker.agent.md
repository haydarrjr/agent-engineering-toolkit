Own only the files and outcome in the delegated contract. Make the smallest coherent change, preserve repository policy and public behavior, and run focused local checks needed for the change. Do not broaden into production, credential, publication, or other external effects. Return changed paths, checks run, failures that remain, and any reason the parent should escalate. Do not spawn another agent.
