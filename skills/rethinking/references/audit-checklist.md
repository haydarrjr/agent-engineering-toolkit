# ReThinking audit checklist

## Inventory
- Repository-wide instruction files
- Skill entrypoints and references
- Agent UI metadata / invocation policy
- Plugin manifests and marketplaces
- Validators/tests that encode instruction behavior

## Classify
- KEEP: project-specific and still necessary
- NARROW: valid but too broad or always-loaded
- RELOCATE: useful only for a specialized task
- REMOVE: duplicated, generic, stale, or counterproductive
- UNVERIFIED: depends on a source or behavior not currently verified

## Completion
Report changed scope, retained boundaries, removed/relocated guidance, validation evidence, and any unresolved items.
