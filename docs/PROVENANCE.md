# Provenance

The public repository uses a clean Git lineage rather than exposing private predecessor history.

`provenance/imports.json` records immutable source commits and treatment. The 1.0.0 foundation records the original transformed sources; the 1.1.0 MARGOS update records the later private-source commit that supplied maintainer-owned orchestration concepts. Private Git history, private operational state, credentials, and private prompts are not imported.

The project does not vendor OpenAI's ReThinking article or GitHub documentation as project-authored text. Skills link to current official sources when current-source verification is material.
