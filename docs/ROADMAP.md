# Roadmap

## 1.0 — OSS foundation
- Portable five-skill package
- Public governance and provenance
- Deterministic source validation
- Reproducible release archive

## Near term
- Collect external install reports across compatible hosts
- Add real-world routing fixtures from community issues
- Add release automation examples for maintainers
- Expand compatibility evidence without adding always-on context

## Later
- Community-contributed skills that meet the narrow reusable-capability bar
- Machine-readable compatibility matrix based on observed host evidence
- Optional maintainer automation examples for issue triage and PR review

Roadmap items are intentions, not compatibility promises.
